# Buenas Prácticas para Redacción de Títulos

## 1. Usar verbos en infinitivo
Ej: "Implementar", "Mostrar", "Permitir".

## 2. Indicar siempre el módulo afectado
Esto facilita el rastreo en el backlog.

## 3. Ser específico y evitar ambigüedades
"Mejorar login" no dice nada; "Agregar validación de contraseña en login" sí.

## 4. Evitar abreviaciones confusas
No uses siglas que no maneje todo el equipo.

## 5. Mantener la consistencia
Usar siempre el mismo estilo facilita la lectura y comprensión del backlog.
