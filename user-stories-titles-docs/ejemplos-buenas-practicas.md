# Ejemplos de Buenas y Malas Prácticas

## Ejemplos Correctos

✅ `[Autenticación] Implementar recuperación de contraseña vía email`

✅ `[Checkout] Permitir pagos con PayPal`

✅ `[Perfil de usuario] Mostrar historial de compras ordenado por fecha`

## Ejemplos Incorrectos

❌ `Hacer pagos`
→ No indica módulo ni acción clara.

❌ `Arreglar error en login`
→ No es claro ni sigue estructura.

❌ `Nuevo diseño`
→ Ambiguo, sin acción ni contexto.
