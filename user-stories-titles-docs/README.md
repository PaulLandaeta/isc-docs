# Estándar para Títulos de User Stories

## Objetivo

Definir un formato estándar y coherente para la redacción de títulos de User Stories, garantizando claridad, consistencia y trazabilidad dentro del backlog del equipo de desarrollo.

## Alcance

Este estándar aplica a todas las historias de usuario creadas por los equipos de Frontend, Backend y QA, con el fin de asegurar una nomenclatura comprensible para todos los miembros del proyecto.

## Estructura del Documento

Este conjunto de archivos incluye:
- Formato propuesto para títulos
- Ejemplos de buenas y malas prácticas
- Buenas prácticas generales
- Referencias utilizadas
