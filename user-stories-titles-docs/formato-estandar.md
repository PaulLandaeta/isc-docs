# Formato Estándar para Títulos de User Stories

## Recomendación Base

Se recomienda el siguiente formato:

[Módulo/Funcionalidad] Acción esperada por el usuario o sistema

## Características del Formato

- **Claridad:** El título debe dejar claro qué se espera lograr.
- **Concisión:** No debe ser demasiado extenso ni incluir detalles técnicos.
- **Ubicación:** Indicar el módulo o funcionalidad afectada.
- **Acción esperada:** Describir brevemente qué debe pasar o realizarse.

## Ejemplo General

✅ `[Perfil] Mostrar datos del usuario al iniciar sesión`
