# Navegación del Repositorio ISC Project

Este repositorio contiene documentación organizada en carpetas temáticas para facilitar el acceso a guías, manuales y documentación técnica del proyecto ISC. A continuación se listan las carpetas disponibles, con una breve descripción y enlace a cada una de ellas en la rama `main` del repositorio oficial.

## 📁 [acerca-de-isc-project](https://github.com/PaulLandaeta/isc-docs/tree/main/acerca-de-isc-project)
Contiene información general sobre el proyecto ISC, incluyendo la estructura del equipo, gamificaciones y métricas de evaluación.

## 📁 [documentación-apis](https://github.com/PaulLandaeta/isc-docs/tree/main/documentación-apis)
Documentación relacionada con el uso, desarrollo e integración de APIs dentro del proyecto.

## 📁 [guías-técnicas](https://github.com/PaulLandaeta/isc-docs/tree/main/guías-técnicas)
Colección de guías específicas sobre prácticas técnicas empleadas en el proyecto.

- **automatizacion**: Buenas prácticas y herramientas para la automatización de procesos.
- **backend**: Guías de desarrollo del lado del servidor y lógica del negocio.
- **convenciones-de-código**: Normas y estándares para mantener la calidad del código.
- **devops**: Procesos de integración y entrega continua, despliegue y mantenimiento.
- **frontend**: Desarrollo de la interfaz de usuario y experiencia del usuario.
- **git-workflow-pr**: Flujo de trabajo en Git y manejo de Pull Requests.
- **qa**: Pruebas de calidad y aseguramiento del software.
- **us-y-tasks**: Definición y gestión de historias de usuario y tareas técnicas.

## 📁 [manuales](https://github.com/PaulLandaeta/isc-docs/tree/main/manuales)
Contiene manuales prácticos y guías paso a paso para facilitar el uso de herramientas o procesos dentro del proyecto.

## 📁 [documentación-acerca](https://github.com/PaulLandaeta/isc-docs/tree/main/documentación-acerca)
Sección complementaria con detalles adicionales sobre el funcionamiento y objetivos del proyecto.

---

> 📌 **Nota**: Asegúrate de estar navegando siempre en la rama `main` del repositorio oficial para acceder correctamente a los documentos.
