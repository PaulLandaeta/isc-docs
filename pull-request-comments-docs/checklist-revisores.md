# Checklist para Revisores de Pull Requests

Este checklist está diseñado para ayudar a cualquier miembro del equipo (QA, devs, PMs) a revisar un Pull Request de forma completa, clara y constructiva antes de aprobarlo o solicitar cambios.

---

## ✅ Checklist General

| Pregunta                                              | Sí | No |
|-------------------------------------------------------|----|-----|
| ¿Se entiende claramente el propósito del PR?          | ☐  | ☐   |
| ¿El título del PR es claro, conciso y específico?     | ☐  | ☐   |
| ¿La descripción del PR explica el “qué” y el “por qué”?| ☐  | ☐   |
| ¿El PR está relacionado a una tarea o issue específica? | ☐  | ☐   |
| ¿Se adjuntó evidencia si era necesaria (capturas, logs)?| ☐  | ☐   |

---

## Checklist de Código (si aplica)

| Pregunta                                               | Sí | No |
|--------------------------------------------------------|----|-----|
| ¿El código sigue las convenciones del equipo?          | ☐  | ☐   |
| ¿Hay pruebas suficientes que cubran los cambios?       | ☐  | ☐   |
| ¿Hay comentarios innecesarios o `console.log` olvidados?| ☐  | ☐   |
| ¿El código es comprensible y fácil de mantener?        | ☐  | ☐   |
| ¿Las funciones/variables tienen nombres significativos?| ☐  | ☐   |

---

## Checklist de Comentarios

| Pregunta                                                       | Sí | No |
|----------------------------------------------------------------|----|-----|
| ¿Tus comentarios son claros y específicos?                     | ☐  | ☐   |
| ¿Formulas preguntas en vez de hacer afirmaciones duras?        | ☐  | ☐   |
| ¿Ofreces sugerencias cuando identificas problemas?             | ☐  | ☐   |
| ¿Evitas juicios personales o tono sarcástico?                  | ☐  | ☐   |
| ¿Tus comentarios promueven una cultura de mejora y colaboración? | ☐  | ☐   |

---

> Este checklist puede adaptarse y actualizarse según las necesidades del equipo.  
> Recordatorio: **un buen revisor no solo detecta errores, también ayuda a construir mejores soluciones.**
