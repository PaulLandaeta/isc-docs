## ¿Por qué es importante comentar bien un PR?

Un buen comentario en un Pull Request no solo mejora el código, sino que también fortalece la comunicación entre los miembros del equipo. Comentarios claros, respetuosos y útiles facilitan la revisión, aumentan la comprensión de las decisiones técnicas y promueven una cultura de colaboración y mejora continua.
